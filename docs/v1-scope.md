# SampleFlow 1.0 计划范围与验收基线

> **状态说明（2026-09-01）：** 本文记录范围和验收基线。P0 与可自动验收的 P1 桌面 Web／仓库工程能力已完成；真实数据 UAT 和公司服务器验收仍未完成。实时执行状态以根目录 [`handoff.md`](../handoff.md) 和 [GitHub Roadmap #18](https://github.com/Eclipseic1848/SampleFlow/issues/18) 为准。

## 问题定义

轻流是订单来源，Excel 是当前业绩核算流水。现状依赖人工复制、正负行调整和线下目标确认，难以统一权限、保留组织归属、审计修改原因并提供实时汇总。SampleFlow 将这些规则固化为公司服务器上的多用户 Web 系统。

## 目标用户

- 销售助理、销售助理组长：监督、逐条录入和追加业绩事件。
- 业务员、业务员组长、业务主管、销售经理：承担目标责任；经理、主管、组长可按层级下达目标，但不得编辑业绩。
- 人事部：最终审批全部目标，可查看并导出，不直接修改目标金额或业绩。
- 总经理：只审批销售经理总目标的第一道节点，可查看并导出。
- 系统管理员：维护账号、角色和组织任职，不自动拥有任何业务编辑权限。

## 核心场景

1. 销售助理按“分子”Sheet3 字段逐条录入或批量导入新订单，校验后确认入账。
2. 已入账订单通过金额差额、整单暂停、重启或首次计入事件调整；同一订单编号保留完整事件链。
3. 上级下达目标，责任人在已认证会话中实名确认；销售经理总目标先经总经理审批，全部目标最后经人事审批。
4. 组织异动后产生的事件归属新组织，历史事件快照不变化。
5. 人事部和总经理导出只读数据后可在外部自行调整，不回写系统原始记录。

## 范围内

- 系统账号登录、首次改密、会话与操作审计。
- 角色权限、账号启停、部门/小组及带生效日期的人员任职。
- 订单台账和不可变业绩事件。
- Sheet3 标准模板、负数应收未收状态，以及协作人/协作比例的个人与组织业绩拆分。
- 目标下达、实名确认、总经理/人事审批、修改申请、下放差额展示。
- 业绩看板、事件/组织汇总、CSV 导出。
- 全部数据表格和可增长清单统一使用默认 10 条、可选 10／20／50／100 条的页码分页。
- 2026 年 1—8 月完整 Excel 明细幂等迁移。
- Windows 一键热更新开发和 Linux Docker Compose 生产配置。

## 范围外

- 轻流 API 自动同步；1.0 仍由人工逐条复制。
- 2024、2025 年订单明细迁移。
- 外部导出文件的二次编辑回写。
- 公司网关、域名、HTTPS 证书、服务器备份策略的实际配置。

## 业务规则

- 入账后不允许更新或删除业绩事件；更正只追加新事件。
- 营业额从 110 调整为 100 时仅追加 -10；调整与暂停是两个先后独立事件。
- 当前正向计入的订单可修改营业额或暂停；应收未收订单可通过营业额调整转为零或正向。暂停后按当前营业额全额扣减，重启时全额正向记入。
- 系统营业额为负表示应收未收，不表示退款或暂停。协作订单按固定比例拆分到主业务员和协作人，公司总额不重复计算；后续调整沿用该比例。
- 零金额订单允许录入但不计业绩，之后通过首次计入事件转为正向。
- 调整记在操作发生月，不重写已签认历史月。
- 个人业绩与团队管理业绩分开；目标可少分配或超分配，并显示差额，主管达成率仍按主管责任目标计算。
- 每一级责任人实名确认具体目标版本；本人只能申请修改，不能让修改直接生效。

## 异常与边界场景

- 重复订单编号返回冲突，不覆盖原订单。
- 暂停状态修改营业额、活动订单直接重启、零金额以外首次计入均被拒绝。
- 非销售助理角色编辑业绩返回 403；系统管理员也不例外。
- 目标已有待签或待审版本时不允许并行创建另一版本。
- 总经理不能审批非销售经理目标，人事部不能跳过销售经理目标的总经理节点。
- 同一 Excel 文件按 SHA-256 识别，重复导入安全跳过。

## 验收标准

- `start_all.bat` 能启动 PostgreSQL、执行迁移和开发 seed、启动 API/Vite 热更新并打开 5174 页面；历史业务 Excel 必须另行受控导入。
- 登录后可按权限完成订单录入和所有合法事件转换，事件金额及发生月计算正确。
- 数据库直接 UPDATE/DELETE 已入账事件被触发器拒绝。
- 销售经理目标完成“实名确认 → 总经理批准 → 人事批准 → 生效”。
- 2026 年明细迁移结果为 4,701 条事件、2,850 笔订单、合计 14,675,659.07 元，重复执行不增加数据。
- 人事部/总经理可导出 UTF-8 CSV；其他角色被拒绝。
- 类型检查、领域测试、生产构建和 1024px／1280px 桌面浏览器检查通过；当前没有移动端。

## 已确认决策

完整决策及理由见 `docs/adr/0001` 至 `docs/adr/0016`。交付形态为公司 Linux 服务器上的 Docker Compose Web 系统；Windows 仅用于热更新开发；开发与生产均使用 PostgreSQL 16。

## 未决问题

- 公司服务器的域名、HTTPS 终止、内网访问策略和备份保留期需由服务器管理员确定。
- 正式生产管理员账号名和初始密码需在部署 `.env` 中设置。
- 轻流自动同步及 2024—2025 历史明细是否进入后续版本尚未决定。
