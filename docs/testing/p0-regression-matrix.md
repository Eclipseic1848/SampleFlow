## 升入门禁的规则

1. 处理某个业务切片时，从本表选择一个最小场景写成失败测试并保存红灯输出。
2. 只实施使该场景通过的最小代码；通过后将测试留在必过套件。
3. 一个代表性测试不能替代该 Issue 验收矩阵中的其他角色、资源或状态组合。
4. #1B 收口时，本表所有适用行都必须有可执行测试路径；不能继续以文档条目代替自动化证据。
