# 系统管理权限与业务权限分离

SampleFlow 设置独立的系统管理员角色，由公司指定人员承担。系统管理员负责账号创建、启用、停用、密码重置、角色分配，以及部门、组别和带生效日期的人员组织关系维护。

系统管理员权限本身不包含目标编辑、目标确认、目标审批、业绩录入、业绩调整、业务查看或业务导出权限。拥有系统管理权限不能绕过销售助理、人事部、总经理等业务角色的既定权限控制。

## Consequences

- 后台导航和接口必须将身份管理、组织维护与业务操作分开授权。
- 系统管理员执行的账号、角色和组织变更必须记录操作人、时间、变更前后内容及组织生效时间。
- 停用账号后必须终止该账号的有效会话，但不得删除其历史签名、审批、业绩事件或审计记录。
- 开发环境可以初始化独立的系统管理员演示账号；生产环境通过受控的首次管理员初始化流程创建首个正式账号。
