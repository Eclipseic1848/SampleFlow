# 分离个人业绩与团队业绩

个人业绩、小组业绩和部门业绩是三个明确区分的统计口径。同一订单事件只作为业务人员本人的业绩记账一次，再根据该事件的组织归属快照汇总形成小组业绩和部门业绩。下属人员业绩不复制或累加为业务员组长、业务主管的个人业绩。

业务员组长使用小组业绩衡量团队管理目标，业务主管使用部门业绩衡量团队管理目标；如果组长或主管本人也产生订单，其订单仅构成本人的个人业绩，同时按相同组织规则进入相应团队汇总。

## Consequences

- 报表和看板必须明确标注个人、小组、部门口径，不能使用含义不清的“我的业绩”。
- 公司业绩总额按订单事件只计算一次，不能将逐级汇总结果再次相加。
- 组长和主管可以同时查看个人业绩与其管理范围内的团队业绩，但二者不得混为同一指标。
- 团队业绩按照每笔事件的组织归属快照计算，因此组织调整不会追溯改变历史团队业绩。
