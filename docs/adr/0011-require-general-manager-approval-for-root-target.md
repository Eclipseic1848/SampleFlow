# 销售经理总目标先经总经理审批再经人事部审批

销售经理总目标是目标树顶层。销售经理依据公司确定的金额在系统中录入并签名，这是“目标责任人不能直接编辑本人目标”的唯一例外。销售经理不能自行批准该目标；总经理只承担该目标的第一道审批，人事部随后执行审批，两道审批完成后销售经理总目标才能生效。

总经理的目标权限仅限审批或拒绝销售经理总目标，不包括修改目标金额。主管、组长和业务员目标均无需总经理审批或抄送。总经理仍无权编辑业绩数据，也无权通过导出后修改的文件反写系统。

## Consequences

- 销售经理总目标必须保留录入人、签名、总经理审批意见和时间、人事审批意见和时间以及目标版本。
- 总经理拒绝后，销售经理修改金额并重新签名，再重新提交审批。
- 人事部不能用自己的审批代替总经理审批，也不能直接修改销售经理总目标。
- 销售经理总目标未通过总经理第一道审批前，是否允许先向业务主管下发目标草稿，需要另行确定。
