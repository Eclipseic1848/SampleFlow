# 总经理可向销售经理下达总目标

2026-09-19，用户明确要求总经理能够下达目标，并确认“总经理下达 → 销售经理确认 → 人事审核后生效”。此决策替代 ADR-0011 中“总经理只能审批”的限制；不改变销售经理自行发起目标的审批规则。

## 决策

- 总经理可选择有效销售经理账号所绑定的人员，填写月份、金额及下达原因；不能据此越级下达部门、小组或个人目标。
- 总经理向其他销售经理下达的总目标，责任人确认后直接交人事终审。下达人、确认人与终审人按稳定人员身份分离；不制造总经理自批记录。验收专用账号仍只受 ADR-0035 的既有例外约束。
- 销售经理自行发起（包括同时兼任总经理但给自己录入）的总目标，仍须本人确认、另一总经理审批、另一人事终审。
- 审批路径由服务端在创建版本时确定，保存在不可修改的 `goal_versions.gm_issued`，不接受客户端指定，也不随后续角色变化重算。
- 迁移033将所有既有版本标记为非总经理下达；保留原金额、状态、确认及审批记录。不得根据现有角色推断历史来源。
- 拒绝后可通过“下达目标”选择同月与同一责任人，填写新金额与原因重新提交，形成新版本。已有待处理或生效版本不能被覆盖。既有下级修改申请、联动调整及生效门禁不变；销售经理联动调整自己总目标仍走原审批链。
- 页面说明下达后的路径，审批待办及按钮依据服务端实际可执行节点展示；兼任人事的下达人/确认人不能看到自己的终审操作。

## 发布与验证边界

使用隔离数据库验证新旧流程、职责分离、拒绝重提、权限过滤、迁移兼容与浏览器操作。客户验收库执行迁移和前后端发布须另行明确批准、先备份；工程测试不等于真实业务验收。不会代客户创建真实目标。
