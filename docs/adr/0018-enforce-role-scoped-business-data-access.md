# 按业务责任范围实施数据查看和导出权限

所有业务列表、详情、看板、导出和审批待办必须由服务端按角色责任范围过滤：业务员仅限本人，业务员组长限本组，业务主管限本部门；销售助理和销售助理组长共同维护全公司业绩账本；销售经理覆盖整个销售组织；人事部和总经理具有全公司只读与导出范围；系统管理员没有自动业务查看或导出权限。

## Consequences

- 销售助理和销售助理组长的全公司范围只用于业绩账本监督、录入和调整，不授予目标编辑、目标审批、账号或组织维护权限。
- 销售经理可查看和导出整个销售组织的数据并编辑业务主管目标，但不能改变业绩事件。
- 人事部可查看和导出全公司数据并执行目标最终审批，不得编辑目标金额或业绩；总经理可查看和导出全公司数据，业务写权限仅限销售经理总目标的第一道批准或拒绝。
- 系统管理员只有在另行具备明确业务角色时，才按该业务角色获得对应范围；系统管理身份本身始终是业务范围 `none`。
- 账号管理页面必须提供只读角色权限矩阵，展示固定角色的业务操作、数据范围、目标职责、导出权限、禁止事项及多角色组合后的实际权限。
- 权限矩阵与服务端授权策略必须来自同一份定义；系统管理员只能分配固定角色，不能逐项勾选、创造或修改业务权限。
- 前端隐藏不构成授权，所有读取、导出和写入入口都必须执行相同的服务端范围策略并具有正向与越权测试。
- 正式业绩报表页面和导出必须使用相同的目标生效门禁；人事部和总经理可以查看准备状态及授权范围内的实际业绩，但未生效目标不得被展示为正式绩效结果。
