# 轻流持有订单基础事实，SampleFlow 初期人工转录

轻流继续作为订单基础事实的权威来源；SampleFlow 不替代轻流维护订单，也不在初期范围内建设自动同步或反向写入。人员依据轻流，通过逐条表单将业绩管理所需的订单信息转录到 SampleFlow；初期不支持批量粘贴或文件导入。SampleFlow 负责目标、签认、业绩调整、权限和报表。该边界避免重复建设订单系统，但会引入人工转录的时效与差错风险，因此必须通过表单校验、操作审计和对账标准控制风险。

## Considered Options

- 由 SampleFlow 替代轻流维护订单：数据入口统一，但会显著扩大迁移、业务流程和验收范围。
- 两个系统都能修改订单：操作灵活，但会产生双向同步、冲突解决和审计难题。
