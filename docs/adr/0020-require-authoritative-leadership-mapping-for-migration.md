# 历史组织迁移必须使用人事确认的负责人映射

`原始数据1.xlsx` 能确定 59 名历史业务员所属的 16 个小组和 5 个部门，但没有组长、主管或负责人任职生效日期。历史组织迁移必须以人事部确认的权威组织映射为输入，为每个小组指定唯一组长、每个部门指定唯一主管及其生效日期；不能从演示账号、角色名称、姓名相似度或业绩数量推断负责人。

## Consequences

- 16 个小组和 5 个部门未全部获得有效负责人前，历史组织迁移不能标记为完成。
- 映射缺失、同一范围存在多个有效负责人、负责人不存在或跨部门错配时，迁移必须失败并生成可审计异常清单。
- 负责人必须先建立稳定人员身份；是否拥有登录账号不影响其历史组织身份，但需要登录执行职责时必须绑定有效账号。
- 每个生效中的小组在任一时刻必须且只能有一名组长，每个生效中的部门必须且只能有一名主管，一个小组只能属于一个部门。
- 同一人员可以同时负责多个小组或多个部门，管理权限范围取所负责单位的并集；管理职责与个人小组成员归属分离，兼管不得改变个人业绩归属。
- 一个人员身份在任一时刻最多只有一个有效小组成员归属；非销售、尚未任职或仅保留历史的人员可以没有归属。
- 任何订单或业绩事件发生时，相关人员必须恰好存在一个有效小组归属，否则录入或导入必须阻断；管理人员本人产生订单时也适用该规则。
- 人员调组必须结束旧归属并开始新归属，任职时间范围不得重叠。
- 负责人离任批次必须同时提供继任者，不能产生无人负责或多人重叠的时间段。
- 映射输入必须记录来源、确认人、确认时间和文件或批次哈希，以便重放和审计。
