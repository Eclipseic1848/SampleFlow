# 入账业绩采用不可变调整事件

未入账草稿可以直接修改；销售助理或销售助理组长完成表单校验并明确确认入账后，记录立即进入正式账本并参与业绩计算，不需要第二人审批。业绩一旦入账，就不得覆盖或物理删除。整单暂停以订单当前全部计入业绩金额产生负向调整事件，重启产生相应正向事件；营业额修改只追加新旧营业额的差额，例如从 110 元变为 100 元时追加 -10 元，不修改原始 110 元记录。调整事件关联原记录，记录原因、操作人和操作时间，并依照 ADR-0001 计入操作发生月。该决策与现有 Excel 的正负流水口径一致，能够保留完整审计链；代价是录入错误会立即影响报表，且同一订单会产生多条关联记录。

## Consequences

- 正式业绩账本不提供覆盖修改或物理删除能力。
- 确认入账是立即生效的明确操作；普通保存只能保留草稿，不能影响业绩计算。
- 确认入账不设置第二人审批，录入者必须在提交前完成表单校验。
- 同一轻流订单编号的暂停、重启和更正必须关联同一业绩主记录，不得复制成新的订单。
- 整单暂停与营业额变更是不同事件：暂停改变业绩计入状态但不改变订单当前营业额；营业额变更改变订单当前营业额。
- 同一订单的事件必须按实际发生时间逐个入账，一个事件不能同时表达营业额变更与暂停或重启。
- 整单暂停金额取暂停事件发生时的订单当前营业额；例如 110 元先变更为 100 元，再暂停时产生 -100 元暂停事件。
- 营业额变更事件只记录新旧营业额的差额，不采用全额冲销再全额记入。
- 只有当前计入业绩金额大于 0 的订单允许修改营业额；暂停订单以及当前计入金额为 0 或负数的订单必须拒绝该操作。
- 暂停订单如需修改营业额，必须先重启至正向计入状态；修改完成后如仍需暂停，再单独执行暂停事件。
- 订单当前营业额为 0 时仍允许确认入账和查询，但不得计入业绩总额，也不得执行营业额修改。
- 零金额订单后来获得正营业额时，必须在同一业绩主记录下新增等于完整正营业额的首次计入事件，不得修改原零金额记录或创建新订单。
- 首次计入事件计入操作发生月；完成后订单才成为正向计入订单。
- 每次调整都必须保留原记录关联、变更原因、操作人和操作时间。
- 报表金额由入账业绩及其调整事件共同计算，不能只读取订单当前金额。
