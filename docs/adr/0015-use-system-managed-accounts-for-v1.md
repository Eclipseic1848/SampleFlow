# 1.0 使用系统自有账号密码

SampleFlow 1.0 使用系统自行维护的账号密码完成身份认证，暂不接入 AD、LDAP、企业微信或钉钉。开发环境提供各角色演示账号以便验收；生产环境必须使用单独创建的正式账号，不能沿用演示凭据。

## Consequences

- 密码只能保存为带随机盐的强哈希，日志、数据库和接口均不得保存或返回明文密码。
- 正式账号必须支持启用、停用、临时密码、首次登录强制修改密码和管理员重置密码。
- 每次登录、失败登录、退出、密码修改和密码重置都必须记录必要的安全审计信息，但不得记录密码。
- 会话必须具有过期时间并支持服务端失效；停用账号后，其现有会话必须失效。
- 开发演示账号只能由开发初始化流程创建，生产部署默认不得创建演示账号。
- 账号、角色和组织关系由独立的系统管理员维护；系统管理员权限本身不授予目标编辑、目标审批、业绩编辑或业务数据导出权限。
