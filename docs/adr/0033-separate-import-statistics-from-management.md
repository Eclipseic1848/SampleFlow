# 导入统计归属与管理授权分离

2026-09-09 用户明确批准：销售助理组长可在导入窗口确认建立缺失人员、统计部门和小组；缺少负责人不再单独阻断入账。此决策调整 ADR-0020 对业绩导入的完整负责人前置要求，保留正式组织任职、目标管理及负责人授权的原有规则。

## 边界

- 复用稳定人员身份和组织单元标识。新建人员无登录账号；统计组织保持未启用，不新增角色或负责人。
- `performance_statistical_assignments` 只保存文件实际业务日期的统计归属，不推断完整任职区间。新的业务日期仍须有正式任职或另行确认的统计归属。
- `import_person_links` 保存当前模板配置内人工确认的精确来源身份关联。已能唯一匹配的身份不得重定向；同名不得自动合并或重复创建。
- 正式任职优先，统计归属仅作为业绩解析的后备。目标成员权限仍只读正式任职，管理范围仍只读正式负责人授权。选择一个已有小组，会按该小组已有的合法业绩查看范围展示新业绩，不增加任何人的授权范围。
- 保存统计资料不入账。原文件及旧预检批次不改写，保存后生成新预检，保留原有重复订单、金额、协作、关闭期间及确认入账校验。
- 统计快照允许负责人为空，不能伪造负责人。后续管理员配置组织或绑定账号，不回填已入账事件的负责人或改变历史金额。
- 普通销售助理不能维护统计资料；销售助理组长也不能通过此入口维护任意账号、角色、正式任职或负责人。

## 发布与回退

- 新增迁移 030，不修改旧迁移；新版本发布前须备份并显式执行迁移。当前实现仅在隔离测试库验证，真实验收库迁移另需授权。
- 不支持在运行旧 API 的同时启用新功能：旧代码不认识新增迁移，也不能消费缺失负责人的统计记录。
- 未写入新统计业务前，可通过部署前备份恢复旧版本。启用后优先前向修复，不能删除人员、统计关联或已入账事件来回退；恢复备份会丢失其后的客户操作，必须另行确认。
