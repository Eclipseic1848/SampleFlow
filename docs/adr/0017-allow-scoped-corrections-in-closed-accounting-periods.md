# 已关闭记账期间只允许受控范围内的追加更正

ADR-0001 继续约束所有正常业绩调整按实际操作月记账，不得通过普通接口回填历史。只有在销售助理组长说明月份、原因、更正类型和相关订单并由人事部批准后，系统才允许对已关闭期间执行一次受控历史更正；批准仅覆盖申请列明的订单和更正类型，不得重新开放整个月份。

## Consequences

- 受控历史更正必须保存真实操作时间，并将记账期间记录为获批的历史月份；二者不能混为同一时间字段。
- 既有业绩事件仍不得更新或删除，历史更正只能追加新事件。
- 人事部只批准或拒绝，不能亲自修改业绩；获批更正只能由销售助理组长执行，普通销售助理不能写入已关闭期间。
- Excel 导入的事件日期落入已关闭期间时，也必须命中获批的订单和事件类型范围；上传文件或确认批次不能绕过重开授权。
- 更正授权只能使用一次，并在获批内容全部执行、人事部主动撤销或批准满 24 小时任一条件先发生时失效；失效后期间自动恢复关闭，继续更正必须重新申请。
- 历史更正完成后，销售助理组长必须重新核对该期间，人事部重新关账并生成新的关账和正式报表版本；旧版本、差异和更正原因永久保留。
- 历史更正改变的是实际业绩，不使金额未变化的目标签名失效；受影响人员收到更正通知，但不新增月度业绩签认流程。
- 未列入获批范围的订单和操作必须继续被拒绝。
- 每次申请、批准、拒绝和更正执行都必须保留审计记录。
- 受控历史更正是 ADR-0001 的窄例外，不能扩展为普通补录或任意历史回填能力。
