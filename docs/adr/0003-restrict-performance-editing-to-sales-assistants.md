# 业绩编辑与目标编辑采用分离权限

业绩编辑、目标编辑、目标申请、目标审批和只读导出是相互独立的权限。只有销售助理与销售助理组长能够执行会改变订单业绩记录或状态的操作；销售经理即使拥有高级管理权限，也不获得业绩编辑权。只有销售经理、主管与组长能够编辑业绩目标；业务员只能提出目标变更申请，不能使修改直接生效。人事部负责目标审批但不能编辑目标或业绩，总经理只能查看和导出。该决策通过职责分离限制高权限角色直接干预业绩，同时保留销售管理层下达和调整目标的职责。

## Consequences

- 权限校验必须作用于所有业绩变更入口，不能因高级管理身份而绕过。
- 目标编辑必须采用独立授权，不能从业绩编辑权限或高级管理身份自动推导。
- 目标申请与目标审批不是目标编辑，三者必须分别授权和审计。
- 后台操作、数据修复和应急流程也必须遵守同一业务权限边界。
- 销售经理发现业绩错误时必须交由业绩数据维护角色处理，不能自行紧急修改。
