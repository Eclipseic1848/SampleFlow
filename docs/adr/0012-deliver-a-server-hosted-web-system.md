# 正式交付公司服务器部署的 Web 系统

SampleFlow 1.0 正式交付为部署在公司服务器上的多用户 Web 系统，不交付单机 EXE 作为生产运行形态。所有角色通过浏览器访问集中服务和数据库，以支持多人同时使用、逐级目标确认审批、统一权限、实时业绩看板和完整审计。

开发过程在 Windows 环境进行。项目根目录必须提供 `start_all.bat`，一键启动前端与后端开发服务；前端必须支持热更新，后端必须支持代码变更后的自动重载，使使用者能够在开发过程中实时查看并验收页面。

## Consequences

- 生产环境需要一台可长期运行、可备份且可受控访问的公司服务器。
- 用户数据和审批状态必须集中存储，不能依赖浏览器本地存储或个人电脑文件作为正式数据源。
- 前端和后端必须具备明确的服务边界，并提供适合 Windows 本地开发的一键启动入口。
- `start_all.bat` 启动失败时必须显示可读错误，不能静默退出；关闭方式和占用端口必须在运行说明中明确记录。
- 公司服务器操作系统、生产部署方式、数据库和访问入口仍需分别确认。
