# 新系统不保留协作人和协作比例

未来业务不再产生协作事件，因此 SampleFlow 不提供协作人、协作比例或协作业绩分配能力。虽然原始 Excel 中存在三条非空协作信息，这些历史值也不进入迁移范围；原始 Excel 文件保持不变并继续作为外部原始材料。该决策保持新系统模型简洁，但意味着迁移后的系统无法查询或还原历史协作关系。

## Consequences

- 新系统的数据模型、录入表单、查询、报表和导出均不包含协作人或协作比例。
- 迁移时明确忽略原始 Excel 的协作人和协作比例列，不将其误判为缺失数据错误。
- 不对历史订单执行协作比例拆分或个人业绩重算。
